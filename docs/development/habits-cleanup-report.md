# Phase 4: habits cleanup

## Inventory, purpose, and file decisions

Eleven original modules implement observed habit evidence, learned pattern reduction,
expectation windows, and production coordination over the shared state plane.

| Original file | Decision | Final responsibility |
| --- | --- | --- |
| `__init__.py` | KEEP, FIX | Canonical exports repaired after consolidation/deletion. |
| `model.py` | KEEP | Immutable observation and coverage contracts with explicit provenance. |
| `store.py` | KEEP, MERGE | Observation/coverage persistence and trusted ingestion. |
| `recorder.py` | MERGE into store.py | Same evidence subsystem; class/method bodies unchanged. |
| `controls.py` | DELETE | Unwired user-facing wrapper, with duplicate pattern signature serialization. |
| `patterns.py` | KEEP, DELETE unused methods | Pattern, suppression and deterministic confidence models. |

| `continuity.py` | KEEP, FIX imports | Production conversation/environment/background coordination. |
| `matrix.py` | KEEP | HABIT domain routing in the default cognition matrix. |

## Production reachability and state ownership

ConversationService constructs HabitContinuityCoordinator and records persisted
user messages using the merged HabitObservationRecorder. BackgroundRuntime calls
runtime coverage, pattern analysis, decay and expectation evaluation. The coordinator
uses scoped observation/coverage reads, pattern support/decay, and expectation
create/resolve; the application matrix projects scoped learned patterns. Matrix
routing is invoked by the default registry. Every serializer/decoder and timestamp/
ID helper is reached through these storage/ingestion operations; model validators
are invoked by construction.

HABIT_OBSERVATION and HABIT_COVERAGE own raw evidence; HABIT_PATTERN owns derived
current patterns; HABIT_EXPECTATION owns separate predictions, not observed facts.
Suppression and invalidation namespaces remain authoritative correction records.
Production observe_support checks both before learning. The explicit storage/engine
suppression and provenance rebuild APIs remain the single correction boundary over
these records; there is no claim that a frontend currently calls them. Their relevant
negative tests verify that recorded corrections govern the live learning path.

## What was wrong, merged, deleted, moved, renamed, and fixed

HabitUserControls and HabitExplanation had no caller outside their own file and
package exports, including no tests or live frontend. Delete the wrapper instead
of retaining a fictitious user-control surface. Its suppression implementation
also copied the canonical pattern_signature payload with different Unicode JSON
encoding; deletion removes this alternate responsibility entirely.

Merge the 112-line recorder into observation store.py (roughly 300 lines), keeping
the trusted ingestion class and append-only store class distinct. Their ownership
is one bounded observation subsystem. Update coordinator, exports and foundation
tests to import from the canonical module; no shim remains. AST comparison verified
the complete recorder class body is unchanged.

Remove unused HabitPattern.coverage_ratio and HabitConfidence.reappraise: neither
had production, test, or diagnostic callers. Confidence score/lifecycle and the
actual engine's support/decay/rebuild remain canonical. Remove the store's redundant
one-line _iso wrapper and call datetime.isoformat directly; remove unused imports.
No move or rename beyond the recorder merge, and no state/schema migration.

## What remains and verification

Nine modules retain separate observation, pattern, prediction and coordination
responsibilities. Historical correction records remain effective. The folder/production gate passed **166 tests** (25.40 s). Full suite:
**3,571 passed, 8 known failures, 2 skipped** (109.83 s), matching the five
unavailable-Ollama and three platform failures, with no new failures. Compile and diff checks
passed. Searches found no retired recorder/controls module imports, wrapper classes,
coverage_ratio or reappraise method in source/tests. No behavioral test was deleted.
