# Phase 5: machine cleanup

## What was there / what it does

Fourteen modules implement platform identity/hardware discovery, validated observations and history, capability adapters, inventory persistence, and operator location configuration. The original per-file definitions/imports/reference inventory follows below. References are lexical candidates; production reachability was checked separately.

Production chain: composition -> MachineToolService -> SQLiteMachineInventoryPersistence / MachineInventoryRefresher -> platform discovery -> MachineInventory. Composition binds machine tools and HardwareInspectionCapability. System inspection, distributed discovery, and desktop settings also consume discovery values. location_cli is an explicit operator entry point; composition reads its locations for HOST environment configuration.

## What I merged / deleted / renamed or moved

Merged the state-plane location registry into location.py and renamed it MachineLocationRegistry. Deleted the competing mutable JSON registry and inventory writer. Split inventory serialization/validation into inventory_codec.py. Preserved read-only legacy import rather than maintaining a compatibility writer or class alias.

## What I fixed

Known-machine CLI lookup now uses the same SQLite inventory as production. Location writes have one canonical namespace. Imports, composition fallback, tests, and current operator documentation use canonical storage. Migration resumes matching partial imports, rejects conflicting canonical records, and retires evidence only after completing import; retirement preserves existing backup filenames.

## What remains

Machine inventory SQLite snapshot ownership is distinct from machine-location state-plane configuration. Stable observations are distinct from transient system inspection results. Historical correction/history APIs remain lifecycle operations, not duplicate state. Platform backends retain Linux and Windows behavior; no live Windows hardware validation was performed. No physical control capability is introduced.
