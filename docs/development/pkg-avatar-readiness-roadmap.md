## Next work, in dependency order

1. **A0 reality check:** pin actual `avatar.json` hash, run exporter in exact checkout, inspect both GLBs in Blender from front/profile/back, inspect meshes/manifests and licensing. Capture Blender version, object counts, import/export transforms and observed problems; do not promote primitive dimensions to canon.
2. **A1b0 proportion setup and measurement protocol:** in a controlled Blender authoring workspace set real-world units, human crown-to-floor height convention, reference pose, world axes, bare-foot origin and mirrored naming. Pin canonical source revision/SHA and character reference rights. Use the **existing** body targets (height 67 in; bust 33 in; underbust 30 in; waist 26 in; hips 37 in), defining repeatable section planes. Capture actual values, error, and `PASS`/`FAIL`/`NOT_RUN`; never confuse bounding-box width with circumference. Weight 135 lb and 30C are reference metadata, not geometry. Mark shoulder, limb, head/face and fox-feature dimensions as proposed/artist-estimated until visually reviewed. **The measurement plan exists; these authoring and measurement actions have NOT RUN.**
3. **A1b actual reusable sculpt:** build one distinctly adult female body to the canonical appearance, approved reference and measured/visually reviewed proportions; required external anatomy, two fox ears and tail near tailbone with human anatomical structures separate. Review sculpt/topology, source/rights and front/side/back views; save controlled authoring `.blend` and verified export hashes. An anatomical detail is not a garment slot or hit-test target. The authoring base is not the public asset.
4. **A1c real rig/anchors:** deformable body with mirrored limbs/fingers, face/eyes, separate ear chains and tail chain; verify real anchor transforms and tail clearance, reference pose, bending and roundtrips. Typed metadata alone does not supply any geometry or bones.
5. **A2 actual garments:** fit underwear/base layers, independently verified fully clothed fallback, engineer jacket/trousers/gauntlets/boots and lounge oversized tee/sweatpants on the SAME body/rig. Check opacity, body coverage, asymmetry, garment collisions, tail/ear openings and clips during sitting, bending, arm raises, gait and tail motion. Garment strings and metadata flags do not establish real coverage.
6. **A3 renderer/privacy:** separate actual rendering process, no accidental unclothed fallback or authoring asset in ordinary runtime export, trusted display/animation receipts, default-denied restricted previews, stop/crash/cache/thumbnail/privacy tests, independently reviewed mapping to INTERACT and resource budget. No represented touch is real touch or sensory proof.
7. **A4/A5 later:** art-backed virtual props and lab, MEM-persisted sourced wardrobe choices, safe preset-based outfit design and eventually supervised sandboxed Blender drafts through DEV/SAFE. No general internet or unsolicited execution.
