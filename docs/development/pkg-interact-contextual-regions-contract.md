# INTERACT: contextual interaction across every canonical region

**Updated user requirement, 2026-09-20:** There is **no anatomically restricted region** in Sofía's represented body. The former hard-coded `_PRIVATE` denial in `InteractionEngine._decide` contradicted Sparks's design. A head pat, tail touch, chest rub and other explicitly described gestures all use the same semantic and decision pipeline, without unconditional acceptance **or** unconditional denial based on anatomy. The retained `Region.private` attribute is **only sensitivity metadata for redacted synthetic exports**, never a permission or policy toggle. It can be renamed in a later compatibility-safe schema change.

## Contract

1. **Recognized is not welcomed.** `InteractionDecision.status='accepted'` means a valid user-described *representational* gesture was classified and source-linked. It does not assert Sofía's assent, pleasure, physical feeling, or a rendered animation. The existing model sees the original saved conversation and bounded region/gesture context and can express a positive, neutral, hesitant, awkward or negative response, or establish a conversational boundary. No region gets a predetermined emotional response. The candidate emotion tuple is optional, includes caution/frustration alternatives, and is never an appraisal written automatically by the gesture ledger.
2. **Stop still works everywhere.** The per-session durable stop command prevents any NEW body gesture, regardless of region; exact resume is a new saved user turn, not blanket consent. Cancelled and unfinished gestures remain denied/acknowledged. Replayed saved message IDs never create second contact or emotion. Multi-action turns with embedded controls are not executed and receive an honest deterministic response.
3. **Questions are not actions.** A tail/chest hypothetical may receive read-only anatomy/context grounding, but it records nothing and cannot change stop state. Uncertain region, quote, code, negation and unsupported composites abstain or request clarification rather than guessing.
4. **Privacy is separate from policy.** Synthetic trace exports redact sensitive anatomy as `[sensitive]` while preserving the actual decision status. In production, the original saved user message and a source-linked gesture ledger contain the region when classified; this is user-local SQLite data, not a public trace. A future privacy/retention review belongs to MEM/SAFE. Synthetic fixture data is never production input.
5. **Dialogue is not a deterministic preference engine.** Correctly varying reactions requires real conversation evidence and model testing. The current code does **not** independently persist a model-stated region-specific boundary; only the explicit session-wide stop is enforced outside the LLM. Do not claim that the model alone provides durable consent, authenticated avatar authority, physical contact or autonomous action. Add a reviewed boundary-commit pathway separately if needed.
