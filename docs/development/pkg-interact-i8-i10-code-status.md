# INTERACT expansion: implemented components and integration gates

**Updated 2026-09-20; verified Windows checkout `0a5769a`.** This is a component-status companion to the [current I1–I16 INTERACT roadmap](pkg-interact-roadmap.md), not evidence that the expansion is live. Changes are on `feature/pkg-interact-shared-engine` / draft PR #2; no `main` merge, production `state/sofia.db` or backup modification, daemon, outbound notification, model call, avatar playback or new permission was made by these standalone components.

## Standalone code, confirmed on Windows

- **I8 vocabulary:** `src/sofia/interaction/registry.py` creates `InteractionCatalog` using current canonical region IDs, complete-name alias resolution with `resolved` / `ambiguous` / `unknown` results, and separate gesture, action and expression vocabularies. Proposed `EMOTION_EXTENSIONS` are not yet registered in the live emotional journal. The v1 parser does **not** consume expanded aliases and verbs yet.
- **I10 revisions:** `src/sofia/interaction/temporal.py` is an opt-in append-only `InteractionStateJournal(path, catalog)` for explicitly sourced preference and boundary revisions, lineage checks and replay protection. `boundary_active` is **not wired into the live interaction guard**. Callers must verify source IDs against saved messages before the journal is trusted in production. Repeated touch never creates enjoyment automatically.
- **I13 expressions:** `src/sofia/interaction/expression.py` represents expression plans, silent/blocked/unsupported states, text-description receipts and separately acknowledged voice/avatar playback. A caller-supplied adapter-verification flag does not constitute authentication; **no actual audio or avatar renderer is implemented**.
- **I15 reciprocal proposals:** `src/sofia/interaction/initiative.py` separates offered from described contact, needs an explicit per-event permission source and checks caller-provided stop and boundary state. It does not independently authenticate that evidence, read the production ledger, choose goals, run idle jobs or deliver messages.
- **Test files:** `test/test_interaction_registry.py`, `test/test_interaction_temporal.py`, `test/test_interaction_expression.py`, `test/test_interaction_initiative.py`. Database tests use only `tmp_path`.
