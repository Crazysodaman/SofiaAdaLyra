## New unverified candidate

`src/sofia/cognition/repetition_guard.py` recognizes long, near-verbatim generated answers against up to eight recent assistant messages in tool-free chat. `OllamaProvider.respond` attempts at most **one** ephemeral rephrase request and returns it only when nonempty and distinct. It keeps the original response on retry failure or further duplication. An explicit request to repeat/quote is excluded; exposed tools, tool calls and tool history are excluded. Each generation retains its own existing content-free performance metrics. There is no database mutation, raw prompt logging, response templating, action execution, or claim that repeated closers and hallucinations are solved. `test/test_ollama_repetition_guard.py` exercises these boundaries with a fake client; it has **not run on Windows** at commit time.
