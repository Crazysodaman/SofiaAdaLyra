# Phase 4: social cleanup

## What was there and what it does

Five modules define authenticated principals, immutable audience/relationship scopes,
durable session binding, and the SOCIAL matrix contribution. All five are KEEP:

| File | Decision | Responsibility and production reachability |
| --- | --- | --- |
| `__init__.py` | KEEP | Public exports of the canonical model, store, and transport helpers. |
| `model.py` | KEEP | PrincipalContext and SocialScope consumed by conversation, scoped memory, emotional and reflection journals, relationship and habit context. |
| `principals.py` | KEEP, FIX | Bootstrap local principal, Discord DM principal, authenticated remote transport principal. |
| `store.py` | KEEP | ConversationService and memory review bind/read the same immutable session/principal/audience record. |
| `matrix.py` | KEEP | Default matrix registry invokes SocialMatrixEvaluator during conversation turns. |

## What was wrong and what was fixed

The remote helper's SHA-256 contract checked only length: arbitrary non-hex text
was accepted, and uppercase representations of the same fingerprint generated a
different audience. Validate exactly 64 ASCII hexadecimal characters and normalize
the audience prefix to lowercase. Existing authenticated production fingerprints
are lowercase, so their stored audience IDs stay unchanged. Regression tests cover
invalid types, length, non-hex ASCII/Unicode, and identical scope across hex case.

## Consolidation and state ownership

No merge, deletion, rename, or move is justified by these five separate responsibilities.
PrincipalContext is the shared immutable value; SocialScope derives scope keys;
SocialSessionStore alone owns session binding. Relationship contact evidence,
habit observations, and emotional events are separate data rather than duplicate
principal stores. The session store already uses transaction-bound connections and
refuses principal/audience rebinding. Its current display-name binding contract is
preserved. Reflection and emotional journals call system_scope in production.
