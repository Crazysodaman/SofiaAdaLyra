# Phase 5: system cleanup

## What was there / what it does

Eight modules supplied Linux/Windows read-only inspection, validated request/result values, production adapters, and an unused in-memory inspection knowledge path. The appended inventory lists original definitions, constants, imports, and candidate callers.

Production reachability: composition -> create_local_system_capabilities -> SystemInspectionCapability -> platform backend.execute -> bounded process/system/network/service handlers. Desktop tray and distributed agent tools also select these backends. Hardware discovery stays in machine; ops converts hardware results into HardwareInspection telemetry. Capability authorization stays in the generic capability boundary.

## File decisions

| File | Decision | Evidence / resulting responsibility |
|---|---|---|
| `__init__.py` | KEEP | Export inspection contracts; remove retired knowledge exports. |
| `backend.py` | KEEP | Abstract backend contract implemented by both production platform adapters. |
| `capability.py` | KEEP | Composition binds local inspection; tray and agent tools use backend factory. |
| `knowledge.py` | DELETE | In-memory cache populated only by tests; production never supplies the optional context fields. |
| `machine_knowledge.py` | DELETE | Association wrapper only constructed by tests; active machine inventory has its own canonical owner. |
| `linux.py` | KEEP | One Linux backend owns procfs/sysfs/systemctl parsing and bounded execution; helpers serve its handlers. |
| `model.py` | KEEP | Immutable request/result and inspection values used by both backends and ops telemetry. |
| `windows.py` | KEEP | One Windows backend owns fixed PowerShell inspection scripts and WMI parsing; helpers serve its handlers. |

## What was wrong / what I deleted

The optional system-knowledge cache had no production writer. Its machine-association facade and cognitive-context injection could be exercised only by constructing them in tests. Deleted both modules and five tests dedicated to that retired architecture. Removed their optional context fields, validators, getter, assembler section, and exclusive structured formatter. This removes a duplicate dynamic observation path while retaining actual inspection results returned through authorized capabilities.

## What I merged / renamed or moved / fixed

No merge, move, or rename was needed. Repaired package exports and cognition imports. The two platform backends are long but each is one OS adapter sharing command transport, validation, error conversion, and observation contracts. Splitting by arbitrary line count would distribute that adapter across helper files; retained the cohesive platform boundary.

## What remains

Canonical stable machine inventory is in machine. System inspection returns bounded transient evidence through production capability execution. No new cached truth, autorun inspection, or physical control was added. Existing backend/request tests continue to cover prohibited arbitrary execution parameters, unsupported platforms, and parsed observations. Live Windows/desktop sessions are not validated here.
