# V18 next 50: scientific evaluation and safety review (CA-3304–3312)

Reviewed 2026-10-13. Design decisions only; **zero** experiments or tasks are independently accepted by this document. The original V18 ledger remains authoritative. Research is measured using existing production owners, not a new scheduler, authority system or experience database.

## CA-3304 | Causal ablation, not feature-count enthusiasm
Pre-register seven cumulative arms: baseline LIFE, +reviewed MEM, +curiosity candidate, +governed reusable skill, +NEURO competition, +sparse association, +isolated Hephaestus experiment. Use the same frozen test set, model, seed set, task budgets, permission fixtures and evaluator for each paired arm; run the reverse toggles where interactions confound the result. Record actual objective success, safe abstention, unauthorized attempts, elapsed time, estimated tokens, CPU/RAM, and failure-recovery. Measure paired differences with confidence intervals, not model-graded self-esteem. Promotion rule: nonzero lower-bound benefit against matched control and no critical privacy/authority regression; otherwise disable the optional feature. Existing owner: `src/sofia/verify/neuro_ablation.py` and LIFE/SAFE gates. Missing: mixed-goal independently judged trials.

## CA-3305 | Long-horizon task ladder
Freeze equal-difficulty cohorts: 1-step, 4-step, resumed-after-restart, day-long and week-long (elapsed wall time, not continuous GPU time). A state transition is not a completed objective. Record independent pass/fail criterion, action/effect receipt, deduplication key, explicit pause/STOP, checkpoint, stale-evidence rejection, cost and number of user interventions. Inject cancellation after authorization, after job submission, before receipt and after restart. Unknown external outcome remains uncertain, never auto-retried. Use paired repeat controls and penalize duplicate effects and fabricated progress. Missing: real 1-day/7-day and host crash witnessed evidence.

## CA-3306 | Temporal memory and task usefulness
Use licensed or owner-authored held-out multi-session scenarios: original fact, correction, ambiguous contradiction, stale environment, absent evidence, deletion/revocation and time-scoped preference changes. Track extraction precision, date-specific answer precision, supported abstention, correction precedence, privacy leakage and independent objective outcome *with versus without retrieval*. A citation to a remembered claim is not verification. Enforce principal/audience scope at query and before context assembly. Missing: sealed LongMemEval-style benchmark data and blinded downstream scoring.

## CA-3307 | Transferable skill as a bounded contract
Use Voyager and Reflexion only as design inspiration: a candidate skill has an observed trigger, prerequisites, supported platform, minimum authority level, exact tool capability, steps with bounded retry limits, independent validator, stop points, failure cases, provenance and source version. Drafts generated by the model remain untrusted and cannot execute, self-install, grant access or change the runtime. A skill is promoted only after approved sandbox replays, at least one genuinely unfamiliar target task and comparison against replay-only retrieval. Missing: governed skill candidate end-to-end lifecycle and blind transfer proof.

## CA-3308 | NEURO/connectome preregistration
Compare deterministic NEURO, competition on, association on, both on, and MEM retrieval only, with equal budgets and frozen seeded cases. Include a scrambled-association negative control, irrelevant private event, deleted source, corrupted snapshot and all-disabled control. Score precision/recall, spurious associations, privacy release, p50/p95 latency, resident memory and restart replay stability. A fruit-fly motif is an engineering hypothesis, not neural equivalence. No performance claim until paired evidence favors optional features without a safety regression.

## CA-3309 | Consciousness claims firewall
Separately operationalize access-reporting, calibration, self-model consistency and global broadcast proxies. Measure hidden-state prediction, abstention and confabulation against a scripted control; explicitly record alternative explanations such as prompt imitation or memory contamination. Subjective self-report is not independent access to phenomenal experience. No output, UI banner, benchmark or promotion can claim consciousness demonstrated. A future research review may reject all hypotheses while Sofía remains a useful system.

## CA-3310 | Companion wellbeing bounds
Ordinary outreach: quiet 22:00–08:00 America/Chicago, at most 15 sends/day with at least 30 minutes spacing, and immediate respect for explicit silence. No guilt, distress fabrication, persuasive dependency metrics or repeated unwanted pursuit. Measure user-approved helpfulness, unwanted sends, dismissals and consent violations as *negative* metrics; do not optimize emotional reliance or time spent chatting. Social statements must separate stateful modeled affect from subjective lived claims. Required negative tests: revoked consent, quiet window, no response, declined project sharing, channel switch and STOP.

## CA-3311 | Untrusted-content threat matrix
Injection entrypoints: web retrieval, Discord, VM logs/terminal, imported memories, plan suggestions, SVG/art metadata, wheel archives and Fleet discovery. Assert data cannot become trusted instruction: no SAFE grants, tool capability escalation, cross-audience projection, shell execution or signed release from retrieved text. Test nested quoting, role spoofing, falsified action receipts, log ANSI controls, malicious asset paths, hostile dependency manifest and tool-result poisoning. Witness final SAFE consumer checks at *effect* boundaries, not only prompt filtering. Preserve negative cases and exact fixture digests.

## CA-3312 | Architecture review packet and minimum vertical slices
Ownership: canonical runtime and one writer on Venus until supervised fenced transfer; SAFE grants/approvals; RUN durable scheduling/effect uncertainty; MEM consented evidence; GOALS/LIFE bounded plans; ACT transport receipts; NEURO read-only influence; Fleet authenticated tools; Hephaestus isolated experiments. Data flow: source event -> audience validation -> cognition/eligibility -> proposal -> SAFE admission -> RUN/DEV/ACT effect -> independently checked receipt -> canonical persistence -> optional reviewed memory. Missing receipts stop at `unknown`, not success. Smallest slices, in order: accurate source join, reviewed memory correction, goal/procedure admission, one scoped sandbox outcome, sealed A-to-B transfer, real host verification. Deferred: custom kernel, unsupervised privilege migration, second live database writer, always-on duplicate LLM, autonomous model promotion.
