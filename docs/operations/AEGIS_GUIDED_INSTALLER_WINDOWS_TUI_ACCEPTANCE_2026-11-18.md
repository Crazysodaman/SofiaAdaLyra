## Owner-facing flow

The end user runs `Aegis-Setup.exe`. The launcher locates the adjacent complete
signed release bundle, requests one UAC elevation, and invokes the bundled
runtime plus the existing canonical guided installer. The user does not need
Git, Python, Rust, Cargo or manual configuration.

The Windows TUI now:

1. Detects host OS, architecture, target and hostname.
2. Discovers and verifies the signed release media and independent installer
   trust root before any effect.
3. Detects an existing canonical installation.
4. Reports free and required disk space.
5. Prompts for installation directory. Default is `D:\Aegis` when a D: drive is
   present, otherwise the reviewed Program Files location.
6. Prompts for terminal TUI launcher, Start Menu shortcut, Desktop shortcut and
   optional start-at-sign-in preference.
7. Produces an exact read-only plan with paths, release/signature identity,
   components, service name, approvals, identity/state retention and startup
   preference.
8. Requires explicit plan confirmation, then uses the existing SAFE/STOP owner
   ceremony and UAC before host changes.

The TUI does not create trust material, install/activate a Core, enroll Fleet,
touch `sofia.db`, or bypass signature/SAFE/STOP checks.
